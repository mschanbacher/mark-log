# Mark Recovery Log

A field log for geodetic survey monuments. Offline-first, installs to your home
screen, stores everything on the device.

## Run it locally

```bash
npm install
npm run dev
```

Open the printed URL. `localhost` counts as a secure origin, so geolocation works
in development without HTTPS.

To test on your phone over your local network, geolocation will refuse to run on a
plain-http LAN address — deploy to the preview URL instead, or run
`npm run dev -- --host` and accept that you'll need to type coordinates by hand.

## Deploy to Cloudflare

1. Push this folder to a GitHub repo. **`package.json` must sit at the repo
   root** — if the repo contains a `mark-log/` folder containing the project,
   either flatten it or set Root directory to `mark-log` in the build settings.
2. Cloudflare dashboard → Workers & Pages → Create → import the Git repository.
3. Build settings:
   - Build command: `npm install && npm run build`
   - Deploy command: `npx wrangler deploy`
4. Deploy. You get a `*.workers.dev` URL with HTTPS. Every push redeploys.

`wrangler.jsonc` pins the asset directory to `./dist` and turns on SPA fallback,
so Wrangler doesn't have to guess.

**If the page comes up blank**, open the build log and look at the uploaded file
list. If it contains `src/App.jsx` or `package.json`, the build never ran and raw
source was served — the build command is missing. A good build logs
`✓ modules transformed`, a hashed `dist/assets/index-*.js`, and `PWA v0.21.x`.

If the build itself fails, it's usually Node: add an environment variable
`NODE_VERSION = 22` and retry.

Netlify is the same shape: build `npm run build`, publish `dist`.

## Install to your phone

Open the deployed URL. **iOS:** Share → Add to Home Screen. **Android:** the
install prompt appears, or Menu → Install app. It then launches without browser
chrome and works with no signal.

## Where the data lives

IndexedDB, in four stores (`src/db.js`):

| store    | holds                                                  |
| -------- | ------------------------------------------------------ |
| `finds`  | your recoveries                                        |
| `photos` | JPEG blobs, keyed to a find, loaded only when you open one |
| `marks`  | the reference mark file, indexed by 0.1° cell          |
| `meta`   | counts and import bookkeeping                          |

The cell index is what keeps a large import usable: a radius query fetches only
the cells covering your bounding box, so a 5-mile search touches a few dozen
cells rather than scanning 100,000 rows. `npm test` checks that the cell query
returns exactly the same set as a brute-force scan.

The app calls `navigator.storage.persist()` on startup, which asks the browser
not to evict the database under storage pressure. Browsers grant this silently
for installed PWAs most of the time, but it is a request, not a guarantee —
**export from My finds periodically.** CSV for records, GPX for your handheld.

Photos are downscaled to 1400px and re-encoded as JPEG at quality 0.72 before
storage, roughly 150–350 KB each. Typical mobile quota runs to a few hundred MB,
so several thousand photos is realistic. The Mark file screen shows current usage.

## Backfilling old photos

Log a find → **From old photos**. Pick photos you already took; the app reads
GPS and capture date out of each one, matches anything within 40 m against a
mark in your file, groups multiple shots of the same disk into a single entry,
and hands you a review list before saving.

Caveats worth knowing:

- Location must have been on when the photo was taken.
- Choose photos from your library. Sending them through a messaging app first
  usually strips the GPS tags.
- HEIC can't be decoded outside Safari. Do the import in Safari, or export the
  photos as JPEG.

## Loading a mark file

NGS Data Explorer (geodesy.noaa.gov/NGSDataExplorer) → draw a box around your
county → export → load the CSV on the Mark file screen. The column matcher
guesses PID / designation / lat / lon and lets you correct it, since exports
don't agree on header names. Coordinates parse as decimal degrees or as
`39 04 12.3` sexagesimal.

## Structure

```
src/App.jsx    all four screens
src/db.js      IndexedDB layer
src/geo.js     distance, bearing, coordinate and CSV parsing, image compression
src/exif.js    EXIF extraction and nearest-mark matching
src/index.css  the whole stylesheet
CLAUDE.md      architecture notes, read automatically by Claude Code
wrangler.jsonc Cloudflare asset directory + SPA fallback
```

Service worker and manifest are generated by `vite-plugin-pwa` at build time —
`registerType: "autoUpdate"` means a new deploy quietly replaces the cached
version on next launch.
